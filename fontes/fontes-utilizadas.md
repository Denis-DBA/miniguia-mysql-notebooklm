# 📚 Curadoria de Fontes

Este projeto foi desenvolvido com base em documentações oficiais e materiais de referência sobre MySQL e SQL. A seleção das fontes priorizou confiabilidade, atualização e qualidade técnica, garantindo que o conteúdo utilizado no NotebookLM fosse consistente e adequado para o estudo.

---

## 1. MySQL Documentation

**Tipo:** Documentação oficial

**Descrição:**

A documentação oficial do MySQL apresenta informações completas sobre instalação, configuração, administração, segurança, conectores, APIs e recursos disponíveis para o banco de dados.

**Motivo da escolha:**

Por ser a principal fonte oficial do MySQL, foi utilizada para garantir informações precisas e atualizadas sobre o funcionamento do sistema.

---

## 2. MySQL 8.4 Reference Manual

**Tipo:** Manual técnico oficial

**Descrição:**

O MySQL 8.4 Reference Manual reúne explicações detalhadas sobre comandos SQL, tipos de dados, funções, otimização, índices, procedimentos armazenados, triggers e administração do banco de dados.

**Motivo da escolha:**

Foi utilizado como principal referência técnica durante a construção do miniguia, permitindo aprofundar conceitos e compreender o funcionamento dos recursos do MySQL.

---

## 3. MySQL Tutorial (W3Schools)

**Tipo:** Tutorial online

**Descrição:**

Material introdutório com exemplos práticos de comandos SQL e funcionalidades do MySQL.

**Motivo da escolha:**

Auxiliou na revisão dos conceitos básicos e na compreensão da sintaxe dos comandos SQL por meio de exemplos simples.

---

## 4. SQL Tutorial (W3Schools)

**Tipo:** Tutorial online

**Descrição:**

Tutorial dedicado aos principais comandos da linguagem SQL, incluindo consultas, filtros, agrupamentos, funções de agregação e relacionamentos.

**Motivo da escolha:**

Foi utilizado como apoio para revisar a linguagem SQL e complementar os conteúdos apresentados na documentação oficial do MySQL.

---

## Considerações finais

A combinação entre documentação oficial e materiais didáticos permitiu construir um conteúdo equilibrado, unindo profundidade técnica e exemplos práticos. O NotebookLM foi utilizado para organizar, resumir e relacionar as informações presentes nessas fontes, facilitando o processo de aprendizagem e a elaboração deste miniguia.
