# 📚 Miniguia de Estudos sobre MySQL utilizando NotebookLM

> Projeto desenvolvido para o desafio da DIO com o objetivo de explorar o NotebookLM como ferramenta de aprendizagem ativa, utilizando fontes confiáveis para construir um guia de estudos sobre MySQL.

---

## 📖 Sobre o projeto

Este repositório reúne um **miniguia de estudos sobre MySQL**, elaborado com o apoio do **NotebookLM** e baseado em documentações oficiais e materiais técnicos.

O objetivo é demonstrar como a Inteligência Artificial pode auxiliar na organização do conhecimento, na revisão de conceitos e na construção de materiais de estudo, mantendo o foco em fontes confiáveis e na validação das informações.

Durante o desenvolvimento do projeto foram utilizados conceitos de curadoria de conteúdo, engenharia de prompts e pensamento crítico para produzir um material estruturado e reutilizável.

## 🎯 Objetivos

- Estudar os principais conceitos do MySQL.
- Utilizar o NotebookLM como ferramenta de apoio aos estudos.
- Organizar conteúdos técnicos de forma estruturada.
- Registrar a evolução dos estudos por meio de prompts.
- Construir um material de consulta para futuras revisões.
- Desenvolver um projeto que também possa compor meu portfólio no GitHub.

---

## 📚 Conteúdo abordado

O miniguia aborda os seguintes temas:

- Introdução ao MySQL
- História do MySQL
- Sistema Gerenciador de Banco de Dados (SGBD)
- Banco de Dados Relacional
- Tipos de Dados
- Comandos DDL
- Comandos DML
- Comandos DQL
- Constraints
- Funções de Agregação
- Operadores SQL
- JOINs
- Views
- Procedures
- Triggers
- Índices
- Backup
- Segurança
- Boas práticas
- Glossário

---

## 🤖 Sobre o NotebookLM

O NotebookLM foi utilizado como ferramenta de apoio para:

- organizar o conteúdo estudado;
- consultar informações presentes nas fontes;
- resumir conceitos técnicos;
- comparar informações entre diferentes materiais;
- auxiliar na elaboração do miniguia.

Todo o conteúdo foi revisado antes de ser incorporado ao projeto.

## 📖 Organização do projeto

Este projeto está dividido em cinco partes principais:

Contém a curadoria das fontes utilizadas durante os estudos.

Documenta os prompts utilizados, os resultados obtidos e os aprendizados durante a interação com o NotebookLM.

### 📁 miniguia

Reúne o material final consolidado sobre MySQL.

Contém exemplos práticos em SQL utilizando conceitos estudados ao longo do projeto.
